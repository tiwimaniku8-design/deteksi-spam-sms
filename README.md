## Struktur Folder
- `data/raw/`: data mentah
- `data/processed/`: data hasil preprocessing
- `notebooks/`: notebook eksplorasi dan eksperimen
- `src/`: kode reusable
- `models/`: model yang sudah disimpan
- `app/`: aplikasi demo
- `docs/`: laporan dan slide
